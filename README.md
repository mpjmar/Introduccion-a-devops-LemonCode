## Introduction to DevOps 🚀

This repository serves as an index of all labs completed during the training.
It includes Docker and Docker Compose configurations, a Laravel backend, MySQL initialization data, a Next.js frontend and a .NET backend exercise.

## 📦 Labs

* [Lab 01 - Base - Full Stack with Docker Compose](https://github.com/mpjmar/LemonCode-Devops-Lab01.git)
* [Lab 02 - Dockerizing backend](https://github.com/mpjmar/02-laboratorio-laravel.git)
* [Lab 03 - Dockerizing a fullstack application](https://github.com/mpjmar/03-Laboratorio-Dockerizando-una-aplicaci-n-fullstack.git)

## 🛠 Covered concepts

- Building and running applications with Docker and Docker Compose.
- Initializing and persisting MySQL data for development.
- Containerizing a backend in Laravel and another in .NET.
- Basic frontend examples using Next.js (in the `frontend/` folders).
